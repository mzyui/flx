pub fn visit_html_table(body: &str, visit: impl FnMut(ParsedProxy) -> bool)
Expand description

Visits HTML table rows, locating IP/port columns from headers.

Falls back to the first two columns when headers are unknown and skips rows with unparseable addresses. Returning false from visit stops the scan early.
