Expand description

Contract every proxy list provider must implement.

The default fetch downloads a source body and the default scrape_with parses it, so most providers only define name and sources.

fn fetch<'life0, 'life1, 'async_trait>( &'life0 self, client: Arc<Client<HttpsConnector<HttpConnector>, Empty<Bytes>>>, url: &'life1 str, timeout: Duration, ) -> Pin<Box<dyn Future<Output = Result<Cow<'static, str>>> + Send + 'async_trait>>
where Self: Sync + 'async_trait, 'life0: 'async_trait, 'life1: 'async_trait,

Downloads url as UTF-8 text, following redirects within timeout.

Returns the full body; rejects non-success statuses, oversized bodies, and non-UTF-8 content.

§Errors

Returns an error when the URL is invalid, the request or body stream fails or times out, redirects loop or exceed the limit, the status is not success, the body exceeds the size cap, or it is not valid UTF-8.

fn scrape_with<'life0, 'async_trait>( &'life0 self, body: Cow<'static, str>, tx: Sender<Proxy>, ctx: ScrapeContext, ) -> Pin<Box<dyn Future<Output = Result<()>> + Send + 'async_trait>>
where Self: Sync + 'async_trait, 'life0: 'async_trait,

Parses body with ctx.mode and forwards proxies to tx.

Rows advertising a protocol keep it, others inherit ctx.default_types; stops early without error when the receiver is closed.

§Errors

Returns an error when the body is malformed JSON for the selected mode or the parser task fails.
